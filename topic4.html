📝 Serial I/O & Transmission Topic 4

The 1-Sentence Story: Serial I/O transmits data one bit at a time over a single wire, using either asynchronous start/stop framing or synchronous block transmission, with hardware like UARTs and shift registers handling the parallel-to-serial conversion.

📌 Definitions & Key Terms

Serial I/O
Transmission of data one bit at a time over a single communication line. Requires fewer wires, suitable for long distances.
Parallel Transfer
Transmission of multiple bits simultaneously over multiple data lines. Fast but expensive and prone to interference over long distances.
Shift Register
Hardware used to convert parallel data (from the CPU bus) to serial data (for the device line) and vice versa.
UART
Universal Asynchronous Receiver/Transmitter. Hardware that performs serial-to-parallel and parallel-to-serial conversion using the asynchronous start-stop format.
USART
Universal Synchronous/Asynchronous Receiver/Transmitter. Supports both synchronous and asynchronous modes.
Baud Rate
The number of symbols transmitted per second.
Bit Rate
The number of bits transmitted per second. Bit Rate = Baud Rate × bits per symbol.

⏳ Asynchronous Serial Transmission (Start-Stop)

🔹 Frame Structure & Synchronization

  • Idle State: Line is held at logic 1.
  • Start Bit: Logic 0. The transition from 1 to 0 signals the beginning of a character.
  • Data Bits: 6–8 bits of actual data.
  • Parity Bit (optional): For error checking.
  • Stop Bit(s): Logic 1, marks the end of the character.
  • Receiver Synchronization: Uses a local clock at 16× the transmission rate. The counter is reset on the Start bit's leading edge. The receiver samples bits near their centers (at 8 ticks) to avoid edge noise. Re-synchronizes at every Start bit.

🔄 Synchronous Serial Transmission

🔹 Block Transmission & Clock Recovery

  • Data transmitted in blocks (hundreds/thousands of bits) instead of small characters.
  • No Start/Stop bits per byte (more efficient).
  • Receiver recovers timing from signal transitions (clock recovery).
  • Beginnings/ends of blocks marked by synchronization codes.
  • Suitable for high-speed communication.

⚙️ UART Internal Architecture (Key Registers)

DATAIN

Holds received data (parallel) for the CPU to read.

DATAOUT

Holds data (parallel) from the CPU to be transmitted.

Status Register

Contains flags like Data Available, Transmitter Ready, and error flags (parity/framing).

Control Register

Sets baud rate, number of data bits, parity, and stop bits.

Shift Registers

Perform the actual parallel-to-serial (TX) and serial-to-parallel (RX) conversion.

📊 Comparison (Serial vs. Parallel)

Feature Serial Parallel
Bits per transfer One at a time Multiple simultaneously
Wires needed Few Many
Distance Long Short
Cost Low High
Speed Slower Faster
🔒 GOLDEN RULE

One bit at a time keeps wiring simple and distances long — while framing and clock recovery guarantee every bit lands in the right place.

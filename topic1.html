📝 Bus Organization & Basics Topic 1

The 1-Sentence Story: A bus is a shared communication pathway that connects the CPU, memory, and I/O devices, using a strict Master-Slave hierarchy to transfer address, data, and control information without requiring dedicated point-to-point wiring.

📌 Definitions & Key Terms

Bus
A shared set of parallel electrical wires used to transfer information between computer components.
System Bus
The common communication path connecting the Processor (CPU), Main Memory, and I/O Devices.
Bus Master
The component that initiates a bus transaction (requests the bus, specifies the operation, and controls the transfer). Example: CPU.
Bus Slave
The component that responds to a transaction initiated by the master (provides or receives data as requested). Example: Memory or I/O device.

🔹 The Three Types of Bus Lines (Crucial for Exams)

📍

Address Lines

Identify the source or destination (e.g., a specific memory address).

e.g. physical address
📦

Data Lines

instruction / data word
⚙️

Control Lines

Read / Write / Interrupt

✅ Key Advantages of Buses

  • Reduces physical connections: Prevents the exponential growth of wiring (scaling).
  • Common path: Standardizes communication across different components.
  • Time-sharing: Multiple components can share the bus, operating in turns.
🔒 GOLDEN RULE

Only one bus master can control the bus at any given time to prevent signal collisions and data corruption.

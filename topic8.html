📝 External Storage & RAID Architecture Topic 8

The 1-Sentence Story: RAID uses multiple physical disks viewed as a single logical disk to improve performance (via striping), increase reliability (via mirroring or parity), and scale capacity, with different levels offering specific trade-offs.

📌 Definitions & Key Terms

RAID
Redundant Array of Independent Disks: a system using multiple physical disks to improve performance and/or reliability, viewed as a single logical disk by the OS.
Data Striping
Distributing data across multiple physical drives to allow parallel access.
Strip
A small unit of data (block, sector) stored on one disk.
Stripe
A set of logically consecutive strips mapped to all disks in the array.
Mirroring
Duplicating data on a second disk (RAID 1).
Parity
A redundancy technique using XOR to recover lost data without full duplication (RAID 3, 4, 5, 6).

📊 RAID Levels (Exam Table)

Level Organization Redundancy Access Fault Tolerance Typical Use
RAID 0 Striping None — Independent None High performance, non-critical
RAID 1 Mirroring Duplicate data 1 disk Independent 1 disk Critical files, small DBs
RAID 2 Bit/word striping Hamming/ECC 1 disk Parallel 1 disk Obsolete
RAID 3 Bit-interleaved parity Single dedicated parity 1 disk Parallel 1 disk Large sequential (CAD, imaging)
RAID 4 Block-interleaved parity Dedicated parity 1 disk Independent 1 disk Rarely used (bottleneck)
RAID 5 Distributed parity Distributed single parity 1 disk Independent 1 disk Most popular; read-intensive
RAID 6 Dual distributed parity Two parity schemes 2 disks Independent 2 disks Mission-critical, high availability

🧮 Parity & Data Recovery (RAID 3/4/5)

Parity Calculation P = D₁ ⊕ D₂ ⊕ D₃ ⊕ D₄
Recovery D₃ = D₁ ⊕ D₂ ⊕ D₄ ⊕ P
⚠️ Small Write Penalty (RAID 4/5): Requires 2 reads (old data + old parity) and 2 writes (new data + new parity).

⚡ Performance Categories

High Transfer Rate

Parallel access across disks.

RAID 0, 2, 3

High I/O Request Rate

Independent access to multiple requests.

RAID 0, 1, 4, 5, 6

High Fault Tolerance

Survives disk failures without data loss.

RAID 1, 5, 6
📌 KEY EXAM POINTS
RAID 0 & RAID 1 do not use parity-based redundancy.
RAID levels represent different architectures, not a hierarchy.
RAID 4's bottleneck: the single dedicated parity disk. RAID 5 distributes parity to solve this.

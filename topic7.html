📝 Direct Memory Access (DMA) Topic 7

The 1-Sentence Story: DMA is a technique where a dedicated controller transfers blocks of data directly between an I/O device and main memory without continuous CPU involvement, freeing the CPU from repetitive data-movement tasks.

📌 Definitions & Key Terms

DMA
Direct Memory Access: a method that allows a block of data to be transferred directly between an I/O device and memory with minimal processor intervention.
DMA Controller
A control circuit associated with the I/O interface that performs memory-transfer tasks on behalf of the processor.
Cycle Stealing
A DMA mode where the controller obtains the bus for one (or a few) cycles at a time, interweaving its memory accesses with the CPU's.
Burst / Block Mode
A DMA mode where the controller obtains exclusive access to the bus and transfers the entire block without interruption.
BR
Bus Request: signal asserted by the DMA controller to request bus control.
BG
Bus Grant: signal asserted by the processor/arbiter to grant the bus.
BBSY
Bus Busy: signal asserted by the current bus master to prevent others from using the bus.

🧩 DMA Controller Registers

Starting Address

The beginning memory address for the transfer.

Word Count

The number of words/bytes to be transferred.

Status & Control

Holds direction and completion settings.

R/W Direction of transfer (I/O to Memory, or Memory to I/O).
Done Set to 1 when the block transfer is complete.
IE Interrupt Enable: if 1, raises an interrupt when done.
IRQ The flag that triggers the interrupt.

⚙️ DMA Controller Functions (for each word)

  • Provides the memory address.
  • Generates bus control signals.
  • Transfers the data.
  • Increments the memory address.
  • Maintains the word count.

🔄 DMA Operation Steps

  1. Initialize: CPU provides starting address, word count, and direction.
  2. Transfer: DMA controller obtains bus control, transfers data, increments address, decrements word count.
  3. Completion: When word count reaches zero, DMA sets Done flag. If IE is enabled, raises an interrupt.

📊 DMA Transfer Modes (Exam Comparison)

Feature Cycle Stealing Burst / Block Mode
Bus Access One/few cycles at a time Entire block at once
CPU Access Interwoven (short interruptions) CPU is completely stalled
Transfer Speed Slower Faster
Best For When CPU must keep running High-speed block transfers

🔀 Bus Arbitration for DMA

  1. DMA controller asserts BR (Bus Request).
  2. Processor responds with BG (Bus Grant), often connected in a daisy chain to multiple DMA controllers.
  3. DMA waits for BBSY to become free (0), then becomes Bus Master and asserts BBSY.
  4. After transfers, DMA releases the bus, and the processor regains control.
📌 KEY EXAM POINT
Program-Controlled I/O: CPU waits (polling).
Interrupt-Driven I/O: CPU does useful work, device alerts CPU when ready.
DMA: Device interface transfers data directly to/from memory, CPU only initiates and is notified at the end.
